GingerbreadWeb (DroidWeb) - Android 2.3-styled browser written in Java 25.
Uses aria2 downloading (very fast) and Swing library instead of JavaFX
Open source, fast browser with performance smelling like gingerbread.
Performance comparison:
Well, let's compare it to Zen browser for example:
